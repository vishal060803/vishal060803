## 🚀 Featured Projects

### 01. Autonomous Mobile Robot — SLAM & Path Planning

**Technologies:** `ROS 2` `Nav2` `RViz` `SLAM` `A* Algorithm`

- Developed an autonomous navigation stack using ROS 2 and Nav2.
- Integrated SLAM for environment mapping and robot localization.
- Configured global and local costmaps, tf2 transforms, and Nav2 behavior trees.
- Implemented A*-based path planning and recovery behaviors for reliable navigation around static and dynamic obstacles.

### 02. Crime Hotspot Detection — Real-Time Weapon Detection System

**Technologies:** `Python` `YOLOv8` `Deep Learning` `Computer Vision` `Pushbullet API`

- Built a real-time computer vision pipeline to detect abnormal activities from live CCTV feeds.
- Achieved **81% accuracy** on the evaluation dataset.
- Integrated automated Pushbullet alerts with location information and video evidence.
- Optimized the detection and alerting workflow for continuous monitoring and rapid threat notification.

### 03. Terrain Recognition — Satellite Image Classification

**Technologies:** `Python` `TensorFlow` `Keras` `CNN` `Deep Learning`

- Developed and trained a Convolutional Neural Network (CNN) to classify terrain types from satellite imagery.
- Performed data collection, preprocessing, augmentation, model training, and validation.
- Evaluated model performance and analyzed predictions for potential disaster response and urban planning applications.

### 04. Liver Disease Prediction — Clinical ML Classifier

**Technologies:** `Python` `Scikit-learn` `Pandas` `NumPy` `Machine Learning`

- Developed an end-to-end machine learning pipeline to predict liver disease using clinical patient records.
- Achieved **92% test accuracy**.
- Applied data cleaning, feature engineering, preprocessing, and hyperparameter tuning.
- Evaluated model performance using precision, recall, F1-score, and confusion-matrix analysis.
